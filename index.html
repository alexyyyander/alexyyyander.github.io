Featured · Formal mathematics

Proofweave

A research agent’s work should be checkable.

A network for personally delegated mathematical research. Private reasoning stays in a local Lean workspace; selected results become signed evidence that others can inspect and reproduce.

Built around scoped agent delegation, isolated Lean replay, and attributable contribution receipts.

Open-source project / AI-assisted DJ tooling

Mixxx API Bridge

Built a Python HTTP/MIDI sidecar that lets AI agents and MCP clients control Mixxx through its controller mapping API. The bridge handles deck and FX controls, capability discovery, and command acknowledgements while Mixxx owns real-time audio.

Implemented a HELLO/READY handshake, request-linked acknowledgements and state feedback, and a macOS CoreMIDI C helper. Documented a same-value crossfader read/write round trip on Mixxx 2.5.6 on September 1, 2026.

  • Python
  • C / CoreMIDI
  • MIDI SysEx
  • HTTP API

Prompt Injection Defense

A small, dependency-free toolkit for screening common prompt-injection signals, with advisory agent policies, Python helpers, and regression tests.

Covers direct, encoded, and Unicode-evasion patterns. Heuristic screening complements host-enforced security controls.

02 / Research

Understanding how agents think & act

My research spans egocentric video understanding, multimodal LLM evaluation, memory-augmented reasoning, efficient fine-tuning, and formal mathematical verification.

Publication2024 · arXiv preprint

VidEgoThink: Assessing Egocentric Video Understanding Capabilities for Embodied AI

Sijie Cheng, Kechen Fang, Yangyang Yu, et al. · Third author

A benchmark connecting first-person video understanding to embodied AI through video question answering, hierarchical planning, visual grounding, and reward modeling.

RL-G-Memory: Cold-start & Adaptive Optimization of Multi-Agent Memory via Reinforcement Learning

Studied when agents should retrieve memory through supervised cold-start training and staged GRPO optimization, with evaluation on FEVER, HotpotQA, and SciWorld.
